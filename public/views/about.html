About MovieFinder

MovieFinder is a web application built with Node.js, Express, and vanilla JavaScript that helps you discover and track TV shows.

Features:

  • Browse thousands of TV shows from the TVMaze API
  • Search and filter shows by genre
  • Create a personalized watchlist
  • Rate shows and track which ones you've watched
